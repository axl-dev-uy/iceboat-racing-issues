# Frostline Racing

Public issue tracker and documentation repository for Frostline Racing.

This repository does not contain the plugin source code. Frostline Racing is closed-source and distributed as compiled releases only.

## Downloads

- [Spigot — Free edition](https://www.spigotmc.org/resources/frostline-racing-beta-ice-boat-minigame.136999/)
- [BuiltByBit — Premium edition](https://builtbybit.com/resources/frostline-racing-beta.117453/)

## Reporting bugs

Please include:

- Frostline version
- Server software and version
- Relevant console logs
- Steps to reproduce
- Arena configuration when relevant

## Feature requests

Feature suggestions are welcome, but requests may not be accepted or implemented.

## Support

Use the Issues tab for reproducible bugs and feature requests.
